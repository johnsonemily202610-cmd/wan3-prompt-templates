# Prompt templates for image-to-video

Reusable templates save time and make results more consistent. Each template below is a starting point; replace the bracketed parts.

## Gentle atmosphere

"[Subject] stays still while [soft motion: light / steam / leaves] moves slowly. Camera remains static."

## Product turn

"The [product] rotates slowly on a clean table. Soft studio light from the left. Camera stays fixed."

## Before and after

Use the before image as the first frame and the after image as the last frame. Prompt: "Smooth transition between the two states, no new objects."

## Map route

"A dotted line traces the route from [A] to [B] on the map. Soft ambient light. Slow camera follow."

## Rules of thumb

One motion per clip. State the camera in its own sentence. Prefer short clips first.

Templates like these work in any image-to-video tool, for example [visit website](https://wan3.io/).
